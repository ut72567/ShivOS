ADB & Fastboot Setup

Android Debug Bridge (ADB) and Fastboot are essential command-line tools required for modifying your device's software.

Developer Options Required Before proceeding, ensure you have enabled "USB Debugging" and "OEM Unlocking" in your device's Developer Options settings.

Windows Installation

1. Download the official Google Platform Tools.
2. Extract the ZIP file to C:\platform-tools.
3. Open Command Prompt and test the connection:

Terminal
cd C:\platform-tools adb devices

Linux / macOS Installation

Most Linux distributions and macOS setups can install platform-tools directly via their package managers.

Bash (Ubuntu/Debian)
sudo apt update sudo apt install android-tools-adb android-tools-fastboot

Unlocking the Bootloader

The bootloader ensures only official software runs on your device. You must unlock it to flash a custom recovery and ShivOS.

Data Wipe Warning Unlocking the bootloader will trigger a factory reset. All personal data, photos, and apps on internal storage will be completely erased. Back up your data first.

Standard Fastboot Method (Pixel, OnePlus, Nothing)

1. Reboot your device into Fastboot mode (usually Volume Down + Power).
2. Connect your device to the PC.
3. Execute the unlock command:

Terminal
fastboot flashing unlock

4. Use the volume keys on your device to confirm the unlock request, and press the Power button to execute.

Install Custom Recovery

ShivOS requires a custom recovery like TWRP, OrangeFox, or the official ShivOS Recovery to wipe partitions and flash the OS ZIP file.

Flashing Recovery Image

Download the device-specific recovery image (.img) for your phone model, place it in your platform-tools folder, and execute:

Terminal
fastboot flash recovery recovery.img fastboot reboot recovery
A/B Partition Devices If your device utilizes A/B slots (most devices launched with Android 9+), use fastboot boot recovery.img instead, and flash the installer ZIP from within the temporary recovery.

Flashing ShivOS

You are now ready to install ShivOS. Ensure your battery is at least 50% before proceeding.

Step-by-Step Installation

1. Boot your device into your Custom Recovery.
2. Go to Wipe > Format Data and type yes.
3. Return to the main menu and select Apply Update > Apply from ADB.
4. Sideload the ShivOS ROM package from your PC:

Terminal
adb sideload ShivOS-v2.x-OFFICIAL.zip

5. Wait for the process to hit 47% (this is normal ADB behavior) and state `Total xfer: 1.00x`.
6. Reboot your system and enjoy ShivOS!
